# Maintenance notes

Implementation context for future maintenance, separate from the public README.
This dotfile is not private: it is visible in a public repository if committed.
YAML and the template are authoritative; avoid recording changing publication
counts, page counts, or API signatures here.

## Rendering contracts

- Preserve full heading elements in show rules. Main sections are H1;
  publication and service categories are H2. Entry titles are ordinary text.
- Preserve source reading order in grids: date/number before content and each
  referee's complete details before the next referee. Footers are automatic PDF
  artifacts in Typst.
- Mark the whole Hindi name, including its space, as Hindi. The regex font rule
  applies Lohit Devanagari to glyph runs; applying it to the space as well changes
  the header's appearance.
- CV defaults and standalone publication settings share a renderer. Changes to
  publication spacing, publisher visibility or contact display must not
  unintentionally change the other document.
- The publication list always includes all records and supplementary links,
  with the application header and no publisher fields. Its link order is
  Conference version, Full version (or Journal version when accepted), then
  other links. A journal invitation alone is not acceptance.
- Publication categories follow YAML group order. Years sort descending, with
  stable ties. Talk occurrences sort by explicit year/month; unknown months
  follow known months in the same year. Groups follow their latest occurrence.
- Preserve all awards, teaching entries, talks and visits in the standard CV
  unless the author explicitly requests a selection change.
